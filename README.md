# Resume Analyzer

An AI-powered Resume Analyzer web application built using **Python and Flask**. The application allows users to upload their resume in PDF format and analyzes the content to provide a resume score, matched skills, missing skills, and improvement suggestions.

## 🚀 Features

* 📄 Upload resume in PDF format
* 📊 Calculate a resume score
* ✅ Identify matched skills
* ❌ Identify missing skills
* 💡 Provide resume improvement suggestions
* 💼 Recommend a suitable job role
* 🌐 Simple and user-friendly web interface

## 🛠️ Technologies Used

* **Python**
* **Flask**
* **HTML**
* **CSS**
* **PyPDF2**
* **Jinja2**

## ⚙️ How to Run the Project

### 1. Clone the repository

```bash
git clone https://github.com/chakalidhanalakshmi081-ai/Resume_Analyzer.git
```

### 2. Open the project folder

```bash
cd Resume_Analyzer
```

### 3. Install the required packages

```bash
python -m pip install -r requirements.txt
```

### 4. Run the application

```bash
python app.py
```

### 5. Open in your browser

```text
http://127.0.0.1:5000/
```

## 🎯 Project Purpose

The main purpose of this project is to help job seekers understand how well their resume matches expected skills and identify areas that can be improved before applying for jobs.
